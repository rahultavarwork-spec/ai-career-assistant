# 🤖 AI Career Assistant

An AI-powered Career Assistant that uses Retrieval-Augmented Generation (RAG) techniques to search and retrieve relevant information from a user's CV.

## 🚀 Features

- 📄 PDF CV processing
- ✂️ Text extraction and chunking
- 🔎 Semantic search
- 🧠 Sentence Transformer embeddings
- 📊 Relevance scoring
- 💬 CV question answering
- ⚠️ Handles unrelated questions
- 🌐 Streamlit web interface

## 🛠️ Technologies

- Python
- Streamlit
- Sentence Transformers
- PyPDF
- NumPy
- Scikit-learn
- RAG

## 📌 Example Questions

- What are my technical skills?
- What is my educational background?
- What work experience do I have?
- What projects have I worked on?
- What are my strengths?
